# Firefox add-on

See the [browser import guide](../docs/browser-extensions.md) for installing
a signed build or loading this directory temporarily, starting the local
webserver and importing tabs.

## Package for development

From this directory in a clean checkout, run `bash build.sh` to create
`szurubooru-toolkit-firefox.xpi` in the parent directory. The build is unsigned.
Use Firefox's temporary installation for local testing.
